# Камера та Завантаження Фото

Цей розділ описує реалізацію функціоналу камери та прямого завантаження фотографій у Supabase Storage.

## Огляд
Функціонал реалізований як автономна фіча `features/TakePhoto`, яка інтегрована в сторінку `pages/camera`. Основна мета — забезпечити швидкий та безпечний спосіб створення знімків безпосередньо з браузера з подальшим завантаженням.

## Архітектура

### 1. Кастомний інтерфейс камери
Замість стандартного системного пікера реалізовано власне вікно перегляду через `navigator.mediaDevices.getUserMedia`. Це дозволяє:
- Відображати "живий" потік відео.
- Перемикатися між фронтальною та основною камерами.
- Робити знімок у форматі `Blob`.

### 2. Пряме завантаження (Direct Upload)
Щоб не навантажувати наш бекенд пересиланням великих файлів, реалізовано наступну схему:
1. Клієнт запитує у бекенда **Signed Upload URL**.
2. Бекенд за допомогою `service_role` ключа генерує тимчасове посилання для завантаження в Supabase.
3. Клієнт відправляє файл безпосередньо в Supabase Storage за допомогою `PUT` запиту.

### 3. Стискання зображень
Перед завантаженням користувач може активувати перемикач "Стискати". Це використовує утиліту `compressImage`, яка:
- Ресайзить фото до максимальної ширини 1920px (зберігаючи пропорції).
- Конвертує в JPEG з якістю 0.8.
- Суттєво зменшує розмір файлу (в 5-10 разів) без суттєвої втрати візуальної якості.

## Безпека та Очищення

### Захист роута
Сторінка камери доступна тільки авторизованим користувачам. Якщо користувач не увійшов у систему, він побачить попередження з пропозицією авторизації. Після логіну спрацює автоматичний редирект назад до камери.

### Cleanup Logic
Камера — це ресурсний процес. Гарантуємо повне відключення камери (індикатор на пристрої згасає), коли:
- Користувач натискає "Закрити".
- Користувач переходить на іншу сторінку через меню.
- Компонент видаляється з DOM.

Це реалізовано через очищення всіх медіа-треків у хуку `useCamera`.

## Використання в коді

### Хук `useCamera`
```typescript
const { videoRef, startCamera, stopCamera, takePhoto } = useCamera();
```

### Фіча `TakePhoto`
Компонент, який можна вставити в будь-яке місце додатку для виклику інтерфейсу камери.
```tsx
<TakePhoto onPhotoUploaded={(url) => handleResult(url)} />
```
